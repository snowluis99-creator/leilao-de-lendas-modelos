# Leilão de Lendas — modelos 3D

Modelos 3D (skin padrão) dos campeões de League of Legends usados no jogo de fã **Leilão de Lendas**,
um projeto gratuito e sem fins lucrativos para jogar entre amigos. Extraídos do jogo instalado e convertidos
para glTF (`.glb`) com a ferramenta em `scripts/modelos/` do repositório do jogo.

A pasta `falas/` tem falas de dentro da partida (dublagem em português do Brasil: abates, pentakill,
provocação, risada, piada, ataque, andar), extraídas do jogo instalado com `scripts/falas/` do repositório
do jogo. `falas/manifest.json` diz quantas falas de cada tipo cada campeão tem.

qualquer pessoa oficialmente envolvida na produção ou gerenciamento de League of Legends. League of Legends e
